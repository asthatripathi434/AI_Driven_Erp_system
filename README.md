# AI_Driven_Erp_system

An AI-powered ERP (Enterprise Resource Planning) system designed to streamline school administration, finance, and student management.  
This project integrates **secure authentication, payment processing, and intelligent automation** to deliver a modern ERP solution.

---

## Features
- 🔐 **Authentication & Security**: JWT-based login with configurable secret keys  
- 💳 **Payment Integration**: Razorpay test keys for online transactions  
- 📊 **Database Management**: MongoDB backend for scalable data storage  
- 📧 **Email Notifications**: SMTP integration for sending alerts and updates  
- 🏫 **School Information System**: Manage student records, classes, and reports  
- 📈 **AI-driven modules**: Automate workflows and detect anomalies  

---

##  Tech Stack
- **Backend:** FastAPI, Python  
- **Database:** MongoDB Atlas  
- **Frontend:** React (ERP Frontend)  
- **Payments:** Razorpay API  
- **Email:** SMTP integration
